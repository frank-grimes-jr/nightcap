# Workspace guidance

[AGENTS.md](AGENTS.md) is the canonical repository instruction file for all coding
agents. Read and follow it before editing or operating this workspace. It owns
subproject commands, protected client paths, backup/cache rules, balance policy,
branch promotion gates and documentation duties.

For current deployment state use [docs/status.md](docs/status.md), then
[docs/next-steps.md](docs/next-steps.md). Dated studies retain historical evidence;
do not infer current production state from their old candidate labels.
