NIGHTCAP MAPS
=============

Easier-to-read EverQuest maps with Nightcap's services marked.
Based on the Brewall map pack (www.eqmaps.info).

INSTALL
1. Close EverQuest.
2. Unzip this file into your EverQuest folder (the one with eqgame.exe).
   You should end up with:
     maps\Nightcap\
     maps\Nightcap Dark\
3. Start the game and open the map window.
4. Pick a set from the dropdown at the top of the map window:
     Nightcap       - for the normal white map background
     Nightcap Dark  - if you set your map background to black
   Your old maps are untouched; pick the default entry to go back to them.

WHAT IS DIFFERENT
- Every line and label meets a high contrast level (WCAG 4.5:1), so white
  and yellow text no longer disappears on the white background.
- Tiny labels are bigger, and zone exits use the largest text.
- Colours still match the legend printed on each map
  (Banker gold, Merchant green, Guild Master grey, Mission teal,
  Tradeskill purple, Zone red).
- New layer 3: Nightcap services, taken from the live server.
    Zone exits Brewall did not mark, bankers, merchants (with what they sell),
    class guildmasters, crafting stations, and NPCs who respond to a hail.
  Services standing together share one label, e.g.
    "Trainers: Warrior, Monk, Rogue".

LAYERS
The map window's layer buttons (0-3) turn each layer on or off:
  0 = walls, 1-2 = Brewall labels, 3 = Nightcap services.
Turn layer 3 off if a busy city feels crowded.

TIPS
- Map background colour is a per-character setting in the map window;
  use Nightcap Dark if you switch it to black.
- Use the Find box to search labels, e.g. "Banker" or "Trainers".
