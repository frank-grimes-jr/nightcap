NIGHTCAP — GETTING STARTED

You need Windows 10/11 (64-bit), Microsoft Edge WebView2 Runtime, and a complete
supported EverQuest Rain of Fear 2 client that you obtained separately. This
download contains the Nightcap launcher, not the complete EverQuest game.
If the game reports missing D3DX libraries, install Microsoft's legacy DirectX
runtime from https://www.microsoft.com/en-us/download/details.aspx?id=8109.

1. Ask the server owner for your private Nightcap username/password and have
   your current public IP approved. These are separate from EQEmu accounts.
2. Make a dedicated copy of your RoF2 folder, such as C:\Games\Nightcap.
   Keep it outside Program Files, OneDrive, and other synced folders.
3. Extract nightcap-friends.zip. Run nightcap-launcher.exe as your normal user.
   Use only the owner's download and compare its SHA-256 if you need to verify it.
   The package is not currently Windows Authenticode signed; Windows may show
   an unknown-publisher warning. Do not disable antivirus or install exclusions.
4. Choose the folder containing eqgame.exe. Check for updates, then install them.
5. Press Play. Keep the launcher open and sign in with your Nightcap account.
   No VPN app, eqhost editing, /loadskin command, or other slash command is needed.

The launcher establishes the encrypted connection automatically. Closing it
ends its game session. If the connection drops, reopen Play and log in again.
The original eqhost.txt is restored after normal exit. If a previous run was
interrupted, the launcher uses its saved original on the next successful run.

If access is unavailable after changing networks, ask the owner to update your
approved IP. If a local port is occupied, close another Nightcap launcher or
local EQ server. Do not run two copies of this launcher on the same PC.

An unsupported-client message means this eqgame.exe is not the supported RoF2
build. Do not rename a different client's executable to bypass the check.
If files are in recovery, use the launcher's recovery action before Play.
New launcher versions are downloaded from the owner; the launcher automatically
checks signed game-file releases when you use Check for updates.

Never send anyone your password, complete log-in packets, or private server files.
SERVER.txt contains the guide address for this release.
