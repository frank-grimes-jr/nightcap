# Nightcap loading screens

Created September 20, 2026 using the built-in image generation tool.

Ten original PNG artworks, each **1672 × 941 pixels** (approximately 16:9), with baked-in NIGHTCAP lettering and a crescent/star emblem. The first four follow the existing player website's deep teal, antique gold and ivory palette. The second four emphasize classic painted fantasy MMORPG imagery, distinctive races and class roles, and brighter varied colors. The ninth portrays a requested Dark Elf paladin loadout; the tenth depicts a gnome combining all three caster pet classes. These are atmospheric fantasy interpretations, not exact depictions of in-game zone geometry or item textures.

The lower portion of each composition is darkened for a future loading tip or progress indicator. No loading text or progress bar is baked in. Preserve the title when adapting to other aspect ratios. Generation introduces small variations in emblem and letter styling between scenes.

All ten images were visually inspected for title spelling, composition and obvious artifacts. Local copies were decoded to verify dimensions and SHA-256 matched against the generated originals. Client format conversion, installation and in-game display validation are not part of this asset-only delivery; the binary client directory was not modified.

Exact prompts are preserved in [PROMPTS.md](PROMPTS.md) for images 01-04, [PROMPTS-classic.md](PROMPTS-classic.md) for images 05-08, [PROMPT-paladin.md](PROMPT-paladin.md) for image 09, and [PROMPT-gnome.md](PROMPT-gnome.md) for image 10 and its item references. Originals are preserved in the Codex generated-images directory. These are the native outputs, with no resizing or sharpening applied.
