# 0078 · Visible equipment ornaments

A cosmetic design is a persistent item definition with its own slot mask and appearance. The artisan consumes one physical donor through the inventory transaction used for Advanced Loot. A new drop roll selects from the same catalog without consulting the zone hunt table. This keeps cosmetics independent of combat progression.

RoF2 has six augment positions. The server projects the effective cosmetic socket at inspection and validation time, preserving source item definitions used by existing equipment contracts. The planner checks every visible host for a usable position. Stable IDs let a socketed design survive later catalog additions. The destination export and paired client determine which models enter the pool.

Implementation and acceptance steps are in [Visible equipment ornaments](../items/visible-ornaments/README.md).
