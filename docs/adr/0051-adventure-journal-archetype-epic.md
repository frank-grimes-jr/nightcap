# 0051 — Native Adventure Journal and one archetype relic

Date: 2026-10-01. Status: accepted intent; implementation candidate.

Use native individual tasks for a Classic adventure campaign. Three shared
chapters lead to five role paths, independent of primary class. Native task
completion is the sole source of earned eligibility.

Reward one all-class charm with five selectable earned attunements. The public
East Commonlands Chronicler controls switching. Store active attunement and the
shared cooldown per character; commit activation before invoking a spell. A
failed or uncertain database operation never authorizes an effect.

Reserve a small explicit spell range for effects that are exempt from Nightcap's
permanent-beneficial-buff policy. Ship the matching native contract, content,
quests and client spell additions together, initially disabled. Preserve data
and owned content on rollback.

Separate archetype items would complicate recovery and encourage effect stacking.
A custom client journal would duplicate native task functionality. Bespoke wave
trials can follow the first campaign after representative build measurements.

Details and acceptance: [specification](../adventure-journal/SPEC.md).
